# Max Vogt — Personal Portfolio

A distinctive digital home for Max Vogt: independent web development, selected work, philosophy, process, and website packages from €500 to €5,000.

## Experience

- Dark editorial design with electric blue and lime accents
- Pointer-responsive 3D code panel with reduced-motion support
- Responsive layouts, keyboard focus states, and semantic navigation
- Three service tiers with contextual package selection
- Lightweight HTML, CSS, and JavaScript; no build dependencies

## Run locally

Requires Node.js 18 or newer.

```sh
node preview.mjs
```

Open http://127.0.0.1:4173. Deploy the contents of `dist/` to a static hosting provider.

## Files

| File | Purpose |
| --- | --- |
| `dist/index.html` | Content, portfolio, services, and metadata |
| `dist/style.css` | Visual system and responsive layouts |
| `dist/script.js` | Tilt interaction and package selection |
| `preview.mjs` | Dependency-free local preview server |

## Before accepting enquiries

Replace the temporary GitHub contact destination with a business email or booking link. The site currently states that direct project enquiries are coming soon. Confirm package scope and final commercial terms before use. Google Fonts is loaded externally; system fonts provide a fallback.
